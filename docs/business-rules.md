# 내용 규칙

이 사이트는 2026년 1월 31일에 끝난 행사의 초대장을 기념용으로 보존하는 페이지다. 아래 사실과 규칙은 과거 기록이므로 바뀌지 않는다. 바꾸는 작업은 보호자의 명시적 요청이 있을 때만 한다.

|---|---|
| 아이 이름 | 오시훈 (남아) |
| 출생 | 2025년 2월 12일 오후 2시 42분, 3.31kg, RH+ O형 |

| 장소 | 다연재, 세종 부강면 갈산길 73 (우)30071, 위도 36.5384699706392 / 경도 127.362736023159 |
| 주차 | 건물 주차장 이용 (안내 사진 `parking.jpg`) |

## 대표 사진 세 장의 역할

- 첫 화면 큰 사진: `SIHUN_23`
- 소개 섹션 프로필 사진: `SIHUN_12`
- 메신저·SNS 공유 미리보기 이미지: `SIHUN_6`

세 역할은 서로 다른 사진이어야 한다는 규칙은 없지만, 현재 배정은 보호자가 고른 것이다. 사진 번호를 바꾸는 작업(파일명 변경, 순서 재배치)을 할 때는 이 세 역할이 가리키는 사진이 바뀌지 않았는지 확인해야 한다. 번호만 바꾸고 역할 지정을 그대로 두면 엉뚱한 사진이 대표로 나간다.

## 사진첩 규칙

- 사진은 `SIHUN_1`부터 `SIHUN_24`까지 빈 번호 없이 이어진다. 번호 사이가 비면 그 자리는 깨진 이미지 타일로 보인다. 사진을 빼면 뒤 번호를 당겨서 연속을 유지해야 한다.
- 번호는 촬영일 오름차순이다. `SIHUN_1`은 태어난 날(2025년 2월 12일) 사진이고 `SIHUN_24`는 2025년 12월 30일 사진이다. 같은 날 찍은 사진끼리의 순서는 자유다(실제로 11번과 12번은 같은 날이며 몇 분 차이로 순서가 뒤집혀 있다). 새 사진을 끼워 넣을 때는 촬영일 자리에 넣고 뒤 번호를 밀어야 한다.
- 처음에는 1~6번만 보이고, '더보기 (18장 더보기)' 버튼으로 7~24번이 펼쳐진다. 더보기 버튼의 숫자는 전체 수에서 6을 뺀 값으로 자동 계산된다.
- '접기'를 누르면 다시 6장으로 돌아가고 화면이 사진첩 제목 위치로 이동한다. 접은 뒤 화면이 사진첩 중간에 머물러 있으면 안 된다.
- 타일을 누르면 그 사진 한 장이 확대되어 보인다. 확대 중에는 뒤쪽 페이지가 스크롤되지 않아야 하고, 닫으면 다시 스크롤되어야 한다. 모달 안에서 이전·다음 사진으로 넘기는 기능은 없다(의도된 범위).
- 촬영일 캡션: 사진 파일에 촬영 일시가 들어 있으면 "YYYY년 M월 D일" 뒤에 "시훈이😍"를 붙여 사진 아래쪽에 겹쳐 보인다. 촬영 일시가 없는 사진은 캡션 상자 자체를 띄우지 않는다. 날짜 없이 "시훈이😍"만 뜨는 상태는 허용하지 않는다.
- 사진은 화면에 들어올 때 비로소 내려받는다. 24장을 한꺼번에 받지 않는다.

## 첫 화면 규칙

- 제목 "시훈이의 첫 생일 👋🏻", 일시 문구, 축하 문구, 버튼 두 개('📷 사진보기' → 사진첩, '📍 위치보기' → 오시는 길)가 차례로 나타난다.
- '👶 시훈이 소개' 버튼은 숨긴 상태가 최종이다. 소개 섹션 자체는 그대로 있고 스크롤로만 도달한다.
- 화면 맨 아래에 "아래로 스크롤" 안내가 흔들리며 표시된다.

## 오시는 길 규칙

- 지도는 행사장 좌표를 중심으로 줌 18에서 열리고, 마커 위 정보창(장소명 + 주소)이 처음부터 열려 있다. 마커를 누르면 정보창이 닫히고, 다시 누르면 열린다.
- '📋 주소 복사'는 도로명 주소 문자열("세종 부강면 갈산길 73")만 복사한다. 우편번호는 복사 대상에 들어가지 않는다. 복사 뒤 "주소가 복사되었습니다." 알림을 띄운다.
- '네이버지도 📍'와 '카카오지도 📍' 버튼은 각 지도 앱의 "다연재" 검색 결과로 연결된다. 특정 장소 상세 페이지로 바꾸지 않은 현재 상태가 최종이다.

## 공통 동작

- 페이지를 300px 넘게 내리면 오른쪽 아래에 '↑' 버튼이 나타나고, 누르면 맨 위로 부드럽게 올라간다. 300px 이내에서는 보이지 않아야 한다.
- 화면에 보이는 문구는 모두 한국어다. 영어는 공유 미리보기 설명문("Sihun's first birthday party invitation")과 자바스크립트가 꺼진 브라우저에만 보이는 안내문 두 곳뿐이며 둘 다 의도된 값이다.
