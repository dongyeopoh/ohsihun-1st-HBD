# 0007. 사진은 원본 그대로 둔다: GPS도 지우지 않고 용량도 줄이지 않는다

날짜: 2026-10-27

## 상황

결정 기록 0005는 사진 17장의 GPS 좌표를 지우고, 24장의 용량(합계 약 23MB, 최대 5.7MB)을 화질을 해치지 않는 선에서 줄이기로 했다. 실제 작업에 들어가면서 보호자에게 두 가지를 다시 확인했다.

- GPS: 사이트 화면에는 보이지 않지만 사진을 내려받으면 촬영 장소를 읽을 수 있다는 점을 설명했다.
- 용량: 긴 변 2000px·JPEG 품질 82로 19장을 시험 변환해(합계 23.0MB → 12.5MB, 촬영 일시 보존 확인) 원본과 나란히 보여 주었다.

## 결정

- 지금 있는 사진의 GPS 좌표는 지우지 않는다. 앞으로 추가·교체하는 사진에도 GPS 제거를 요구하지 않는다.
- 용량도 줄이지 않는다. 시험 변환 결과를 본 뒤 보호자가 "그냥 원본으로 다 올려줘"로 결정했고, 변환본은 버리고 원본을 그대로 쓴다.
- 0005의 결정은 전부 이 결정으로 대체된다.

## 검토한 대안

- GPS 제거(0005의 원래 결정): macOS 기본 도구 `sips`는 메타데이터를 골라 지우지 못해 별도 도구 설치가 필요했다. 보호자는 노출 위험을 알고도 그대로 두는 쪽을 택했다.
- 용량 축소(0005의 원래 결정): 시험 변환은 성공했고 화면 캡션도 유지되었지만, 보호자가 원본 화질을 택했다. 휴대폰에서의 로딩 속도보다 기념 사진의 원본 보존이 우선이다.
- 메타데이터 전부 삭제: 캡션이 사라진다. 0005에서 이미 기각.

## 결과

- 사진 파일은 어떤 가공도 하지 않는다. 새 사진을 추가할 때도 촬영 일시만 있으면 되고, 크기·용량·GPS 조건은 없다.
- 공개 범위에 "사진 메타데이터 안의 촬영 위치"가 포함된다. 이 범위를 좁히는 쪽으로 바꾸는 것도 보호자가 직접 결정해야 한다.
- 남은 일 목록에서 GPS 제거와 용량 축소가 모두 빠진다.
- 시험 변환에 앞서 만든 원본 복사본(저장소 밖 `ohsihun-1st-HBD-원본사진` 폴더)은 저장소의 사진과 같은 내용이므로 지워도 된다.
