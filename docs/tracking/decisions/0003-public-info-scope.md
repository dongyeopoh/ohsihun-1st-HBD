# 0003. 아이 개인정보 공개 범위를 현재 상태로 확정한다

날짜: 2026-10-20

## 상황

사이트는 누구나 볼 수 있고, 아이 이름·출생 연월일시·몸무게·혈액형·사진 24장·행사장 주소가 모두 공개되어 있다. 행사가 끝난 뒤에도 계속 공개할지, 일부 항목(혈액형, 출생 시각 등)을 빼거나 비밀번호를 걸지 결정이 필요했다.

## 결정

현재 공개된 범위를 그대로 유지한다. 이 범위가 상한이며, 여기에 없는 정보(가족 실명, 연락처, 계좌번호, 집 주소 등)는 추가하지 않는다.

## 검토한 대안

- 일부 항목 제거: 혈액형과 출생 시각은 초대장 관례상 넣는 정보이고 보호자가 공개를 원했다.
- 비밀번호 보호: 정적 호스팅에서는 진짜 보호가 되지 않고(클라이언트 측 검사뿐), 이미 초대장 링크를 받은 사람들이 다시 볼 때 불편해진다.
- 사이트 비공개 전환: 기념으로 남겨 두는 것이 목적이라 맞지 않는다.

## 결과

- 공개 범위를 넓히는 모든 변경은 보호자의 직접 요청이 있어야 한다.
- 사진 파일 안의 GPS 좌표는 이 결정 당시 보호자가 몰랐던 항목이라 따로 결정했다. 결론은 "GPS는 지우고 촬영 일시는 남긴다"이며, 이 결정의 공개 범위에 GPS 좌표는 포함되지 않는다.
