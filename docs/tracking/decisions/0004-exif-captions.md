# 0004. 사진 캡션 날짜를 EXIF에서 자동으로 읽는다

날짜: 2026년 1월 코드 반영 (커밋 "사진 제목 기능 추가", "사진 제목 format 수정"), 2026-10-20 기록

## 상황

사진첩 24장에 촬영 날짜를 보여 주고 싶었다. 날짜를 사진마다 손으로 적은 목록을 코드에 두는 방법과, 사진 파일 안의 촬영 일시를 브라우저에서 읽어 자동으로 보여 주는 방법이 있었다.

## 결정

브라우저에서 exifr로 각 사진의 촬영 일시를 읽어 "YYYY년 M월 D일" 형식으로 보여 준다. 촬영 일시가 없는 사진은 캡션을 아예 띄우지 않는다.

## 검토한 대안

- 날짜를 코드에 직접 적는 방법: 사진을 바꿀 때마다 목록도 같이 고쳐야 하고, 둘이 어긋나면 틀린 날짜가 나간다. 사진 순서를 여러 번 바꾸던 시기(커밋 "사진 순서 수정", "사진 수정 원복")에 특히 부담이 컸다.
- 빌드 시점에 날짜를 추출해 JSON으로 두는 방법: 빌드 단계가 하나 늘고, 보존 단계 프로젝트에 빌드 스크립트를 추가할 만큼의 이득이 없다.

## 결과

- 사진 파일은 촬영 일시(`DateTimeOriginal`)를 반드시 품고 있어야 한다. 메타데이터를 지우는 도구로 사진을 가공하면 캡션이 사라진다.
- 사진마다 파일을 한 번 더 요청한다(EXIF 읽기용). 네트워크 탭에 요청이 두 번 보이는 것은 정상이다.
- 캡션 날짜는 EXIF에 적힌 촬영지 현지 날짜 그대로이며, 보는 사람의 시간대로 환산되지 않는다.
